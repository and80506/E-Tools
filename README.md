## 🌟 项目愿景：做时间的朋友

在信息碎片化和市场噪音喧嚣的当下，个人投资者最缺的不是资讯，而是**独立的思考与纪律的执行**。
`Value-Invest-Sys` 并非一个自动化的量化交易程序，而是一个“数字化投资手账”。它鼓励你：
- **算清底牌**：用数据和估值模型（如 DCF 和段永平法）评估安全边际。
- **沉淀逻辑**：通过沉浸式的全局与个股复盘笔记，记录每一次买卖的思考。
- **守住隐私**：所有核心数据和交易记录完全保存在本地，你的财富密码只属于你自己。

## 🔥 核心功能亮点

### 📊 资产追踪与深度管理
- **一键自选**：便捷添加自选股，随时追踪关注的核心标的。
- **高效直达**：股票代码直达东方财富网，无缝切换查看详细行情。
- **多维标签**：支持自定义分类（如：白马股、收息股、困境反转、观察仓），构建灵活的股票池。
- **交易日记**：快捷录入历史买卖操作，独立抽屉视图清晰展示单次交易盈亏与买卖逻辑。
- **现金流透视 (FCF)**：一键计算 TTM 自由现金流及收益率，支持跨期数据智能相加，看透企业真真实现金创造能力。

### 📉 大盘宏观风向标
- **跨宽基对比**：一键切换沪深 300、中证 500、中证 1000 等核心宽基指数，迅速把握不同市值风格的市场温度与强弱分化。
- **硬核财务还原**：深度对接金融开放平台，通过底层公式（总营收 = 总市值 / 市销率）精准反演并还原真实的指数总营收绝对值，全过程零估算、零模拟数据。
- **周期水位刻度**：结合营收与市值的双 Y 轴直方图对比，以及直观的 PE（市盈率）历史折线走势图，辅以虚线参考带，帮您清晰判断当前大盘所处的周期水位。

### 📝 沉浸式复盘笔记系统
- **全局与个股双线并行**：
  - **全局复盘**：记录每日/每周大盘走势、行业轮动规律及整体投资心态感悟。
  - **个股复盘**：精准锚定单只股票，记录基本面变化、技术面异动或买卖点计划。
- **现代化编辑器**：深度集成 Markdown 语法，支持丰富排版，让思考跃然纸上。
- **时光机热力图**：直观的日历热力图展示，复盘历史一目了然，支持快速跳转查阅过去的投资心得。
- **专注模式**：全屏沉浸式写作体验，搭配快捷键（`Cmd/Ctrl + S` 局部保存），排除干扰，专注总结。

### 📈 价值投资者专属估值模型
摒弃凭感觉的盲目交易，用经典模型寻找确定性：
- **段氏估值法 (隐性预期倒推)**：通过当前市值和企业真实现金流，一键倒推当前股价所隐含的永续增长率预期，判断市场情绪。
- **三阶段 DCF 模型**：支持高速增长期、过渡期、永续期的自由现金流精细化贴现估值，量化评估股票安全边际。

### 🧮 长期主义复利计算器
- 直观的复利收益演算工具，支持动态调整年化收益率与投资年限，帮您具象化长期财富增长目标，坚定持有信心。

### 🛡️ 100% 隐私安全与局域网部署
- **数据自主掌控**：纯本地数据存储 (SQLite / JSON Fallback)，彻底告别云端数据泄露焦虑。
- **极简部署**：提供一键启动脚本 (`start.sh`)。
- **多端共享**：支持在本机运行，亦可在家庭或办公室局域网内通过手机、平板、电脑跨设备无缝访问。

## 🚀 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 8.0.0
- (可选推荐) Python 3.x (用于支持大盘宏观指标数据的智能抓取)

### 安装与运行

```bash
# 1. 克隆项目
git clone https://github.com/your-username/Value-Invest-Sys.git
cd Value-Invest-Sys

# 2. 一键启动并自动安装依赖
# Windows 用户请双击运行或在 CMD 中输入：
start.bat

# Mac/Linux 用户请在终端运行：
./start.sh

# *注意：启动脚本会自动帮您检测并执行 npm install 和 pip install（如果安装了 Python）。

> **🎉 启动成功！** 终端会打印出本地访问地址及局域网 IP 地址，打开浏览器即可开始您的投资复盘之旅。

## 📁 项目架构

本项目采用轻量级的全栈架构，易于二次开发和定制：

```text
Value-Invest-Sys/
├── server/               # 后端 Express API 服务 (轻量高效)
│   ├── index.js          # 服务入口
│   ├── db.js             # SQLite 本地数据库服务
│   └── routes/           # RESTful API 路由模块
├── src/                  # 前端 Vue 3 源码 (响应式与现代 UI)
│   ├── api/              # 前端 API 接口封装
│   ├── components/       # 模块化组件 (复盘、自选股、估值工具等)
│   ├── App.vue           # 根组件及布局
│   └── main.js           # Vue 应用入口
├── scripts/              # 辅助运维脚本 (包含 Node 与 Python 数据爬虫)
├── data/                 # SQLite 数据库文件及种子数据的存储目录
├── public/data/          # 供 GitHub Pages 使用的静态预构建数据目录
├── start.bat / start.sh  # Windows/Mac 一键启动与依赖智能修复脚本
├── build.bat / build.sh  # 生产环境一键构建脚本
└── package.json          # 项目依赖配置
```
